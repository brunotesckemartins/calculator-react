# Calculadora Simples - React Native + Expo

App de calculadora feito para a disciplina de Soluções Mobile (Engenharia de Software - UniSATC).

## Funcionalidades

- Display com o valor digitado e o resultado
- Operações básicas: soma, subtração, multiplicação e divisão
- Números decimais
- Botão de limpar (C)
- Tratamento de divisão por zero

## Tecnologias

- React Native
- Expo
- React Native Paper (componentes visuais)
- Hooks (`useState`)

## Como rodar

```bash
npm install
npx expo start
```

Abra com o app **Expo Go** no celular ou aperte `w` para abrir no navegador.
